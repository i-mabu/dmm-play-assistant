# DMMプレイ自動化アシスタント（単一タブ）

| 項目 | 内容 |
|---|---|
| バージョン | v1.0.0（manifest.json） |
| 状態 | 個人利用中 |
| 稼働先 | 利用者の Chrome（デベロッパーモードで読み込む） |
| 実装 | JavaScript（Chrome 拡張機能、Manifest V3） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## 📖 概要

開いている1つのプレイページだけを対象にする Chrome 拡張機能です。
タブを増やしたり、複数タブを同時に開いたりはしません。

## ✨ 機能

1. **プレイ自動化（メイン）**
   画面上のボタンを探して、優先順に押してプレイを進めます。
   - ダイアログの「閉じる／OK／決定／確認」を閉じる
   - 「受け取る／一括受取」などの報酬を受け取る
   - 「オート／AUTO」があれば押す（バトル用）
   - 「スキップ」「次へ／進む／タップ／スタート／出撃」などで前に進める
   - ボタンが見つからず画面が静止していたら、会話送りとして登録ポイントを1回押す
   - **お金が絡むボタン（購入／チャージ／課金／有償など）は絶対に押しません。**
     ガチャ系は「無料」「チケット」を含む場合だけ押します。
   - 押したボタンはセッション記録に残ります（Muse への報告に含まれます）。
   - 制限: DOM探索はボタンが文字として読めるUIが対象です。Canvas に描かれた文字は読めませんが、
     下の「画像マッチング」でボタンを画像として登録すれば Canvas 内のボタンも押せます。
     クエスト選択や編成のようなタイトル固有の判断はできません。
2. **読み込み見張り**
   画面（ゲーム画面・DOM・リソース読み込み）の変化を見張り、進んでいる間は再読み込みしません。
   設定した分数（既定5分）まったく変化が無ければ、止まったと判断して1回だけ再読み込みします（上限3回）。
3. **進行クリック**
   画面が設定秒数（既定4秒）静止したら、登録ポイントを1回押します。会話送りや「次へ」待ちの想定です。
   真っ白・真っ黒な画面では押しません。
4. **繰り返しクリック（周回）**
   登録ポイントを順番に、設定した間隔で押し続けます。

### 追加機能

- **テンプレート画像マッチング**: パネルの「🖼 画像で登録」でボタンの名前を入れ、ゲーム画面上のボタンを
  ドラッグで囲んで登録すると、その画像をゲーム画面から探して自動で押します（Canvasタイトル向け）。
  色味（赤−青）もスコアに加え、登録サイズの前後（0.8倍/1.25倍）でも探すマルチスケール対応です。
  しきい値はパネルで調整でき、実行間隔は3秒に1回に間引いて負荷を下げています。
- **キーボード会話送り**: 会話送りの方法をクリック／Spaceキー／Enterキーから選べます。
- **長押し**: クリックの長押し時間（ミリ秒）を設定できます。
- **1タブ巡回**: URLリスト（1行に1つ）と1件あたりの滞在分数を設定すると、同じタブのまま順番に開いて回ります。
- **時刻スケジュール**: 自動開始・自動停止の時刻を設定できます（プレイページを開いたままにしている場合）。
- **稼働時間帯の制限**: 指定した時間帯の間だけ動作します。
- **危険ワードで即停止**: 「購入確認」「メンテナンス中」「通信エラー」などが出たら即停止し、デスクトップ通知します。
  ダイアログ（モーダル等）の中は全ワード、ページ本文は強いワード（購入確認など）だけを見ます。
  ワード自体もパネルで編集できます。
- **ゆらぎ**: クリック位置と間隔にランダムなゆらぎを持たせます（ON/OFF可）。
- **1日のクリック上限**: 上限に達したら自動停止して通知します。
- **ホワイトリスト方式**: 登録した文字のボタンだけを押す厳格モードです。
- **スクリーンショット保存**: 手動ボタン、または「停止時にスクショ保存」で自動保存します。
- **デスクトップ通知**: 停止理由（上限到達・危険ワード・スケジュール等）を通知します。
- **操作レコーダー（記録と再生）**: パネルの「⏺ 記録開始」→ 手動でふだん通り操作 →「⏹ 記録終了」で、
  クリック位置（ゲーム画面に対する%）と Space/Enter キー、操作間隔をシナリオとして保存します。
  モードを「シナリオ再生」にして開始すると、その手順を再生します（繰り返し再生も可）。
- **タイトル別プロファイル**: モード・ポイント・登録画像・シナリオ選択などをプレイページごとに保存し、
  次にそのページを開いたときに自動で適用します。巡回と組み合わせると、タイトルごとに最適な設定で回せます。
- **行き詰まり検知**: 操作しても画面が変わらない状態が設定回数（既定3回）続くと、自動で停止して通知します。
  DOMボタン探索でも、同じボタンを押しても画面の文字が変わらない場合は検知して知らせます。
- **DOMボタンの探索範囲**: button / a 以外に、onclick 付き要素や cursor:pointer の要素（divボタン等）も対象です。
- **追加ドメイン対応**: 別ドメインの iframe で動くゲーム向けに、対象ドメイン（例: *.game-example.com）を
  パネルから追加できます。追加時にそのドメインへのアクセス許可が求められます。
- **再起動後の復帰**: 稼働開始時刻と巡回の滞在タイマーを保存し、ブラウザやページを再読み込みしても
  最大稼働時間と巡回の続きを引き継ぎます。

### クールダウンについて

DOMボタン探索の同一ボタンクールダウン、画像マッチングのテンプレート別クールダウン、
会話送りのクリック後ウェイトは設けていません。画面が落ち着いたら即座に次の操作へ進みます。
行き詰まり検知（押しても画面が変わらない場合の抑制と通知）は無限クリック防止のため残しています。

## 🎛️ 設定項目

設定はパネルから変更し、`chrome.storage.local` の `mpaSettings` に保存されます（全フレームで共有）。

| 設定 | 既定値 | 説明 |
|---|---|---|
| モード | play | play（プレイ自動化）/ watch（見張りのみ）/ advance（進行クリック）/ repeat（繰り返しクリック）/ scenario（シナリオ再生） |
| 静止判定（秒） | 4 | 画面がこの秒数静止したら会話送りする |
| クリック間隔（秒） | 2 | 繰り返しクリックの間隔 |
| 無変化で再読み込み（分） | 5 | 見張り: この分数変化が無ければ再読み込み |
| 最大稼働（分） | 60 | 稼働の上限時間 |
| ポイント | (50%, 78%) | クリック位置（ゲーム画面に対する %） |
| 会話送り | click | click / space / enter |
| 長押し（ミリ秒） | 60 | クリックの長押し時間 |
| ゆらぎ | ON | クリック位置・間隔のランダム化 |
| 1日のクリック上限 | 0（無制限） | 達したら自動停止 |
| 稼働時間帯 | 制限なし | HH:MM の範囲内だけ動作（日またぎ可） |
| 自動開始/停止 | なし | HH:MM で自動的に開始・停止 |
| 危険ワードで停止 | ON | 危険ワード検知で即停止 |
| 行き詰まりで停止（回数） | 3 | 0で無効 |
| 画像マッチングしきい値 | 26 | 小さいほど厳密（5〜80） |
| 停止時にスクショ保存 | OFF | 停止時にスクリーンショットを保存 |
| ホワイトリスト方式 | OFF | 登録した文字のボタンだけ押す |
| 1タブ巡回 | OFF | URLリストを同じタブで順に開く（滞在は既定3分/件） |

## 🤝 Muse 連携

- セッション中の出来事（開始・停止・モード・クリック回数・自動再読み込み）を記録します（再読み込みをまたいでも残ります）。
- パネルの「📋 Museへ報告をコピー」で報告文をクリップボードにコピーできます。
  その時点のスクリーンショットも一緒に保存されます。
- 「💾 ログをJSONで保存」で記録をファイルとして残すこともできます。
- なお、拡張機能から Muse へ直接自動送信する仕組みは入れていません
  （送り先の受け口が常時動いている保証がないため、確実なコピー方式にしています）。

## 🛡️ 安全装置

- Escキーで即停止
- 最大稼働時間（既定60分）で自動停止
- 自動再読み込みは1セッション3回まで
- 対象は拡張機能を入れたタブのページだけ。他のタブには触りません
- お金が絡むボタンは絶対に押さない（上記）

## 📝 使い方

1. パネルでモードを選ぶ（見張りのみ／進行クリック／繰り返しクリック）
2. 必要なら「＋ ポイント登録」を押してから、ゲーム画面の押したい場所を1回クリックして位置を登録
   （未登録の場合は画面の横50%・縦78%の位置を押します）
3. 「開始」を押す。止めるときは「停止」ボタンか Escキー

## 🚀 セットアップ

1. このフォルダをPCに置く（または `./build.sh` で作る `dist/dmm-play-assistant` フォルダを使う）
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダを選ぶ
5. DMM GAMES / FANZA GAMES のプレイページを開くと、右上にパネルが出る

## 📁 ファイル構成

- `manifest.json` — 拡張機能の定義（Manifest V3）。本体は `content_scripts` の `js` 配列に並べた5ファイルが同一スコープで順に実行される
- `content/01-settings-utils.js` — 本体1: 設定・定数、小物ユーティリティ、画面（canvas）状態、クリック／キー送信
- `content/02-dom-hunter.js` — 本体2: DOMボタン探索（プレイ自動化）とテンプレート画像マッチング
- `content/03-storage-player.js` — 本体3: 設定の保存・読み込み、操作担当フレーム（`runPlayerFrame`）
- `content/04-top-frame.js` — 本体4: 見張り担当（最上位フレーム。パネル／見張り／巡回／記録）
- `content/05-recorder-main.js` — 本体5: 操作レコーダー、Esc停止、起動処理
- `background.js` — サービスワーカー（スクリーンショット、通知、追加ドメイン登録）
- `tests/` — Node 標準テストランナーによる単体テスト（`npm test`）
- `tools/` — 構文チェック（`check.js`）、パッケージ作成（`package.js`）、アイコン生成（`gen-icon.js`）

## 🛠️ 開発

## ⚠️ 注意

- ゲームが別ドメインの iframe で動いている場合、そのフレーム内でこの拡張機能が動けないことがあり、
  その場合はクリック自動化が効かないことがあります（見張りの再読み込み判定はページ側の変化でも行います）。
- ゲーム画面が canvas で描かれていても、セキュリティ制限でピクセルを読めない場合は変化検知が弱くなります。
- **利用規約について**: 多くのタイトルは自動化ツール・マクロの使用を利用規約で禁止しています。
  アカウント停止等のリスクを理解したうえで、自己責任で使ってください。
- 課金・ガチャ等のお金が絡む操作は自動化の対象にしないでください（ポイント登録先に注意）。
